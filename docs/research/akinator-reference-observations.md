# Akinator Reference Observations

## 직접 플레이 상태

공식 Akinator 웹은 Cloudflare/bot 차단으로 직접 3타깃 플레이 로그 확보에 실패했다. 우회/스크래핑은 하지 않는다.

대신 공개 설명, 앱스토어 메타데이터, 위키/게임 소개 페이지, 스크린샷 경로를 기반으로 interaction primitive를 추출했다. 이후 사람 브라우저 또는 접근 가능한 환경에서 실제 3~5타깃 플레이 로그를 추가해야 한다.

## 관찰된 핵심 원리

1. 사용자가 먼저 비밀 타깃을 마음속에 정한다.
2. 한 번에 질문 하나만 나온다.
3. 답변은 5단계다.
   - Yes
   - No
   - Probably
   - Probably not
   - Don’t know
4. 질문은 고정 설문이 아니라 답변에 따라 적응적으로 바뀐다.
5. 추측 타이밍은 고정 마지막이 아니다.
6. 확신이 높으면 조기 추측한다.
7. 틀렸을 때 회복/학습 루프가 있다.
8. 캐릭터 감정/애니메이션은 장식이 아니라 추론 인터페이스다.
9. thinking/suspense는 긴장감을 만든다.

## Food 서비스 적용 원칙

- 시작 문구는 “오늘 뭐 먹고 싶은지 제가 맞혀볼게요.”
- 질문은 단일 카드로 유지한다.
- 5답변은 한국어로 로컬라이즈하되 의미 구조를 유지한다.
- 질문은 취향조사가 아니라 후보를 가르는 속성/상황 질문이어야 한다.
- reveal은 결과 카드가 아니라 “맞혔다”의 쾌감이어야 한다.
- 오답은 실패가 아니라 “용의 메뉴 제외 → 회복 질문”으로 이어진다.

## Non-copy boundary

- 지니/램프/마법사/파란 캐릭터 금지
- Akinator 이름/문구/데이터/API 금지
- 화면 구성/색/포즈/애니메이션 직접 모방 금지
- 가져올 것은 secret-target guessing game 구조뿐
